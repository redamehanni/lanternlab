Chaîne du matériel

Ici tu prépares ce que les situations utiliseront. Rien ne se déclenche dans cet écran — tu ranges les pièces.

  1. Média imposé — le point de départ : visible dès l’étage 0, distinct des autres objets.
  2. Bureau — les objets de l’étage 1. Liste éditable : contenu, nature, analyses. Importez un objet déjà créé depuis Tous les objets.
  3. Objets recouvrables — tout ce qui se débloque plus tard (code, lieu, balise). Même raccourci d’import.
  4. Résumé — tous les objets, par famille ou par étage. C’est aussi l’éditeur principal.

Ensuite, dans Aventure, tu les branches dans QUAND / SI / ALORS.
