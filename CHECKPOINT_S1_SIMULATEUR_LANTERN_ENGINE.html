5. Comment lancer Magellan

5.1 Via l’interface

  1. Démarrer le backend (cd backend && npm run dev ou équivalent).
  2. Ouvrir http://localhost:4000/lantern-sim/.
  3. Clé lab déjà préremplie : mazone-lantern-sim.
  4. Cliquer le preset « Magellan — Paris 13e @ 17:07 → Monsieur X » (ou 1er → Y, 7e → V).
  5. Lire : Rule rule_talkie_magellan_x MATCH, actions ring + play Monsieur X, var talkie_branch = X.

5.2 Via curl

curl -s -X POST http://localhost:4000/api/admin/lantern-lab/simulate \ -H 'Content-Type: application/json' \ -H 'X-Lantern-Sim-Key: mazone-lantern-sim' \ -d '{ "fixtureId": "magellan", "event": { "type": "media.discovered", "at": "2026-08-09T15:07:00.000Z", "payload": { "mediaItemId": "talkie_magellan" } }, "lat": 48.8322, "lng": 2.3561, "now": "2026-08-09T15:07:00.000Z" }'

Attendu : UI plan ring_talkie + média label Monsieur X. Hors fenêtre (ex. 16:00) → aucune Rule fired, talkie quand même marqué découvert.

6. Comment lancer Appel 20h17

6.1 Succès (Bureau + cassette consommée)

  1. UI : preset « Appel 20h17 — Bureau + cassette → ring ».
  2. Ou API one-shot avec fixtureId: "appel20h17", runtime cassette consumée, event time.schedule / scheduleId: "appel_20h17", coords Bureau (~48.8606, 2.3376), at 20:17 Paris (2026-08-09T18:17:00.000Z UTC en août).

Attendu : ring_phone, audio Appel_20h17, appel_20h17_deja_recu = true.

6.2 Miss (hors Bureau)

Preset « hors Bureau → miss » : pas de sonnerie, flag manqué, occurrence expirée — un second passage au Bureau ne récupère pas l’appel unique.

6.3 Variante E0b (délai relatif, sans attendre 17 min)

  1. Nouvelle session fixture appel_relatif.
  2. Preset / event : media.consumed sur note_batisseur → job pending due +17 min.
  3. Champ Tick to = 2026-08-09T16:20:00.000Z (ou bouton Tick) au Bureau → sonnerie.
L’horloge du simulateur (now / tickTo) est injectée : vous ne dependez pas de l’heure réelle de votre Mac pour tester 20h17 ou +17 minutes.

9. Limites assumées (avant Test Terrain)

  • Sessions en mémoire — perdues au restart du backend.
  • Pas de GPS / QR / NFC / notifications / audio réels sur téléphone.
  • Pas d’EAS / Development Build / Internal Preview.
  • Pas de vue « Test Terrain » live branchée sur un device Paris.
  • Pas d’éditeur de Lanterne (Lab créateur) — seulement exécution de fixtures.
  • Pas encore d’endpoint « Pourquoi ? » dédié (J1) — la trace candidates/fired suffit pour analyser.
  • Zones Paris = approximations cercle (suffisant Golden, pas cadastre officiel).
